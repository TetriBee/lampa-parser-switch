публиковать его не нужно. Он только для вас — чтобы не искать заново, что

## Как пользоваться

В Lampa: **Настройки → Парсер** → вставить адрес и ключ → «Добавить парсер».
Эти значения можно вставлять в плагин — он их сохранит в `localStorage`
телевизора.

## Что полезно помнить

- **JacRed — это форк Jackett, API-ключ ему не нужен.** Ключ требуется только
  обычному Jackett (в таблице — двум адресам ByLampa).
- **Протокол различается.** Часть инстансов отвечает только по `http`. Плагин
  проверяет оба варианта и записывает в настройки рабочий — Lampa берёт
  протокол из ссылки как есть.
- **В браузере на https-странице** http-инстансы блокируются как mixed
  content, и в «веб-версии» Lampa они будут «Недоступны». На ТВ Lampa работает
  по http, там доступны все.
- **Проверять вручную** (нужен браузерный User-Agent, иначе nginx может
  отдать 403):

  ```bash
  curl -s -A "Mozilla/5.0" "http://<адрес>/api/v2.0/indexers/all/results?apikey=<ключ>&Query=test" | head -c 200
  ```

  Ответ `200` и JSON с `Results` — инстанс живой и CORS у него настроен
  (иначе запрос из приложения не пройдёт).
