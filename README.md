# Lampa — «Переключение между парсерами»

Плагин для [Lampa](https://github.com/yumata/lampa-source): список своих
торрент-парсеров и переключение между ними прямо из настроек.

**Описание плагина:** добавьте свои ссылки на Jackett/JacRed с API-ключами и
переключайтесь между ними в один тап — без ручного ввода в настройки Lampa.

Автор: **TetriBee** · лицензия MIT · установка одной ссылкой.

## Возможности

- **Свой список парсеров.** В разделе «Парсер» появляются поля «ссылка» и
  «API-ключ» и кнопка «Добавить парсер». Добавить можно сколько угодно.
- **Переключение в один тап.** Выпадающий список с вашими парсерами — в
  разделе «Парсер» и в отдельной папке «Парсеры».
- **Резервный парсер.** Lampa умеет опрашивать две ссылки и склеивать выдачу —
  плагин этим пользуется: если основной инстанс лежит, работает резервный.
- **Проверка доступности.** Плагин спрашивает тот же API, что и сама Lampa, и
  показывает, кто жив, а кто нет. Проверяются оба протокола (http/https).
- **Автопереключение.** Если текущий парсер упал, плагин сам переключается на
  рабочий (или на резервный) и показывает уведомление.
- **Удаление.** В списке парсеров удерживайте «ОК» на ненужном — удалится.
- **Никаких чужих адресов.** Плагин не поставляет ни ссылок, ни ключей: список
  заполняете вы, руками.

## Установка

Плагин ставится как любой другой: **Настройки → Расширения → Добавить плагин**,
и в поле вставить ссылку на файл `plugin.js`.

<details>
<summary>Готовые ссылки</summary>

```text
https://cdn.jsdelivr.net/gh/TetriBee/lampa-parser-switch@main/plugin.js
https://TetriBee.github.io/lampa-parser-switch/plugin.js   # после включения Pages
```

</details>

> **Почему не `raw.githubusercontent.com`?** GitHub отдаёт оттуда файлы с
> `content-type: text/plain` и `x-content-type-options: nosniff`. Браузер
> (а значит и Lampa на ТВ) такие скрипты **не выполняет** — плагин молча не
> загрузится. Нужен хостинг, который отдаёт JavaScript с правильным типом:
> GitHub Pages или CDN вроде jsDelivr. Официальный плагин Lampa с
> `cub.red/plugin/etor` отдаётся как `text/javascript` — по этому же принципу.

Подробная инструкция (в том числе для LG/Tizen и для своего магазина плагинов) —
в [docs/INSTALL.md](docs/INSTALL.md).

После установки Lampa попросит перезагрузиться — согласитесь.

## Как пользоваться

1. **Настройки → Парсер** — внизу раздела:
   - **Парсер — ссылка** и **Парсер — API-ключ** — вставьте адрес и ключ;
   - **Добавить парсер** — парсер попадёт в список и сразу станет активным;
   - **Парсер** — выпадающий список ваших парсеров, переключение в один тап.
2. **Настройки → Парсеры** — папка плагина:
   - **Парсер** — основной парсер;
   - **Резервный парсер** — запасной (при выборе включается режим «две ссылки»);
   - **Автопереключение** — проверять парсеры и переключаться на рабочий;
   - **Список парсеров** — список со статусами доступности (долгое нажатие — удалить);
   - **Проверить доступность** — прогнать проверку всех парсеров.

Значком `✓` / `✗` в выпадающих списках отмечены доступные и недоступные парсеры.

После переключения настройки применяются сразу: `jackett_url`, `jackett_key`,
`parser_torrent_type`, `parser_use_link` и `jackett_interview` — это ровно те
ключи, которые читает сама Lampa при поиске торрентов.

## Свой список хранится на телевизоре

Парсеры, которые вы добавили, лежат в `localStorage` приложения
(`parser_switch_user_list`) — это их список, они никуда не отправляются.
Никаких файлов редактировать не нужно.

## Про протокол

Часть инстансов работает только по `http`, часть — по обоим. Плагин проверяет
оба варианта и записывает в настройки тот адрес, который реально отвечает, —
Lampa использует протокол из ссылки как есть.

Учтите: если сама Lampa открыта по `https` (веб-версия в браузере), браузер
заблокирует запросы к `http`-инстансам, и такие парсеры будут отмечены как
недоступные. На телевизоре Lampa работает по `http`, там всё в порядке.

## Что плагин меняет в настройках Lampa

| Ключ | Значение |
|------|----------|
| `parser_use` | включает использование парсера |
| `parser_torrent_type` | `jackett` (по умолчанию) или `prowlarr` |
| `parser_use_link` | `one`, `two` или `both` (резервный парсер) |
| `jackett_url` / `jackett_key` | основной парсер |
| `jackett_url_two` / `jackett_key_two` | резервный парсер |
| `jackett_interview` | `all` или `healthy` |

Свои ключи (в `localStorage` Lampa): `parser_switch_user_list` (ваш список),
`parser_switch_main`, `parser_switch_backup`, `parser_switch_auto`,
`parser_switch_status`.

## Совместимость

- Lampa 3.x (проверено на 3.4.7).
- webOS TV, Tizen TV, десктопный браузер, Android — везде, где работает Lampa.
- Минимальная версия приложения: `Lampa.Manifest.app_digital >= 300`.

## Про блокировки и чёрные списки

Плагин ставится обычной ссылкой и **никак не «регистрируется»** в Lampa: если
его адрес не попал в чёрный список, он просто работает.

Чёрный список Lampa (`src/core/plugins.js`) — это список **строк адресов**, и
подставляется он как подстрока: блокируется всё, что содержит совпадение.
Сейчас в серверном списке (`/api/plugins/blacklist`) лежат в основном:

- плагины с рекламой и перенаправлением на монетизацию (их сканер ищет
  `location.href`, `mc.yandex.ru`, `eval(`);
- плагины, отключающие платные функции CUB;
- отдельные онлайн-кинотеатры и 18+;

а также несколько доменов авторов, добавленных **жёстко в самом приложении**
(`bylampa.github.io`, `scabrum.github.io`, `xiaomishka.github.io`,
`andreyurl54.github.io`, сокращатели ссылок, `t.me/`, `4pda.`, `teletype.in`).

В этом плагине нет ни одного из этих паттернов: нет рекламы, редиректов,
`eval()`, отключения премиума и 18+ контента — только переключение настроек
парсера. Ровно так же работает штатный `etor` с официального `cub.red`, который
в списке не значится.

Если адрес плагина всё же попадёт в чёрный список, Lampa не сломается: она
просто перестанет его загружать (при ручной установке покажет «Ошибка
подключения»), а парсер можно будет прописать вручную в
**Настройки → Парсер**.

### Если хотите не трогать «магазинные» режимы

Плагин возвращает раздел «Парсер» в сборках из магазина и снимает «облегчённый»
режим — примерно как это делает штатный `etor`. Если такой сброс не нужен,
поставьте в `plugin.js` два флага в `false`:

```js
enable_torrents_section: true,  // вернуть раздел «Парсер»
disable_light_mode: true        // снять read_only / demo
```
