# Установка на телевизор

Плагин ставится в Lampa как обычный плагин-расширение: отдельная программа не
нужна, всё внутри приложения.

## Коротко

1. Откройте **Настройки → Расширения** (в некоторых сборках — «Плагины»).
2. Нажмите **Добавить плагин**.
3. Вставьте ссылку на файл `plugin.js` из этого репозитория:

   ```text
   https://raw.githubusercontent.com/TetriBee/lampa-parser-switch/main/plugin.js
   ```

   или, если репозиторий опубликован через GitHub Pages:

   ```text
   https://TetriBee.github.io/lampa-parser-switch/plugin.js
   ```

4. Lampa предложит перезагрузиться — нажмите **Да**.
5. После перезапуска зайдите в **Настройки → Парсеры**.

## Если раздела «Расширения» нет

В сборках Lampa из магазинов LG и Tizen часть возможностей выключена
(«белый» режим). Раздел «Расширения» появляется, когда установлен плагин
`etor`:

```text
http://cub.red/plugin/etor
```

Но в этом репозитории `etor` уже не нужен: плагин «Переключение между
парсерами» сам включает раздел «Парсер» и снимает ограничения
(`torrents_use`, `read_only`, `demo`).

## Если Lampa из официального магазина не показывает раздел «Парсер»

Раздел «Парсер» на странице настроек появляется только при
`window.lampa_settings.torrents_use = true`. Плагин выставляет этот флаг при
загрузке, поэтому:

- установите плагин и **перезапустите Lampa** (не просто закройте окно);
- если раздел всё ещё не появился — проверьте в настройках, что включён
  «Парсер» (вкладка «Парсер» → «Использовать парсер» → «Да»).

## Свой магазин плагинов (необязательно)

Lampa умеет открывать сторонний магазин плагинов по ссылке. В этом репозитории
лежит готовый файл [`store.json`](../store.json) с одной записью:

```json
{
  "results": [
    {
      "title": "Парсеры",
      "results": [
        {
          "name": "Переключение между парсерами",
          "link": "https://TetriBee.github.io/lampa-parser-switch/plugin.js",
          "descr": "Переключение между публичными парсерами прямо из настроек.",
          "instruction": "Установите плагин и перезапустите Lampa."
        }
      ]
    }
  ]
}
```

Опубликуйте его рядом с плагином (например, как `store.json` на GitHub Pages)
и откройте в Lampa: **Настройки → Расширения → (другой магазин)**. Формат
соответствует тому, что ожидает `src/interaction/extensions/main.js` в исходниках
Lampa: массив `results`, в каждом — `title` и список `results` с полями
`name`, `link`, `descr`, `instruction`, `author`, `icon`.

## Частный репозиторий и описание

- **Описание репозитория** (поле «About») — это просто текст в шапке. Оно
  ни на что не влияет: плагин устанавливается по прямой ссылке на `plugin.js`.
  Смело ставьте, а если не хотите — пропускайте.
- **Видимость важнее описания.** На бесплатном тарифе GitHub Pages работает
  только для публичных репозиториев, поэтому:
  - если репозиторий **публичный** — ссылки из README работают, и другие
    люди смогут поставить плагин;
  - если репозиторий **приватный** — Pages не запустится, а `raw.githubusercontent.com`
    для приватного репозитория без токена не отдаёт файлы. Тогда плагин придётся
    раздавать со своего хостинга (или попросить автора сделать репозиторий
    публичным).

## Обновление

Плагин обновляется так же, как устанавливается: добавить ту же ссылку заново и
перезагрузить Lampa. Ваш список парсеров при этом сохраняется — он лежит в
`localStorage` приложения.

## Если ничего не работает

1. Откройте в браузере страницу с логом Lampa (в webOS: `http://<ip-телевизора>:port/?debug` или
   DevTools в MSX) и посмотрите консоль — там будут сообщения плагина.
2. Проверьте, что файл `plugin.js` открывается по своей ссылке и отдаёт
   JavaScript, а не страницу с ошибкой 404.
3. Проверьте, что после установки в разделе **Настройки → Парсер** появились
   поля «Парсер — ссылка» и «Парсер — API-ключ».
4. Убедитесь, что на телевизоре работает интернет: без сети статус всех парсеров
   будет «Недоступен».
